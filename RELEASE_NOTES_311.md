## FlipLab 3.1.1 — починил обновление с GitHub

Главная жалоба: «нажимаешь Обновить, приложение пишет, что качает обновление с GitHub, и дальше ничего не происходит». Причина была в скорости и в отсутствии обратной связи.

### Что изменилось

- **Загрузка в 8 потоков.** GitHub режет скорость на одно соединение (~50 КБ/с) — установщик в 30 МБ качался 10 минут. Теперь файл тянется восемью параллельными соединениями: **55 секунд вместо 600** (проверено, хеш совпадает с оригиналом).
- **Прогресс-бар.** Пока качается, в правом нижнем углу показывается панель: сколько мегабайт скачано, сколько всего и процент. Раньше приложение просто молчало.
- **Приложение нормально закрывается** после запуска установщика: раньше `window.close()` мог не сработать, и установщик висел с просьбой «закрыть программу». Теперь есть явная команда закрытия через несколько секунд.
- Если часть потоков не удалась — докачка одним соединением не теряется.

### Как проверить

1. Поставить 3.1.0 (или любую старую версию).
2. «Настройки → Проверка обновлений → Проверить» → появится окно обновления.
3. «Обновить» → в правом нижнем углу пойдёт прогресс-бар (например «7,0 МБ из 29,4 МБ — 23 %»), через минуту запустится установщик, приложение закроется, новая версия откроется сама.
